AP Calculus AB & BC Formula Reference

1. Vertical vs. Horizontal Cross Sections

• Perpendicular to the x-axis (Vertical, dx): Slice width is vertical across the base region: s(x) = |f(x) - g(x)|. Integrate with respect to x from a to b.
• Perpendicular to the y-axis (Horizontal, dy): Slice width is horizontal across the base region: s(y) = |f(y) - g(y)| (Right minus Left). Integrate with respect to y from c to d.

2. Standard Cross-Section Area Formulas (Base = s)
Square: A = s²
Semi-Circle (diam s): A = (π/8)s²
Full Circle (diam s): A = (π/4)s²
Equilateral Δ: A = (√3/4)s²
Isosceles Right Δ (Leg): A = (1/2)s²
Isosceles Right Δ (Hyp): A = (1/4)s²
