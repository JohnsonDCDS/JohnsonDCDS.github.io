Fundamental Theorem of Calculus (FTC) Guide

Connecting Rate Graphs f(t) to Accumulation Graphs F(x)

1. FTC Part 1: The Derivative of an Accumulation Function

If f is continuous on [a, b], then the function defined by F(x) = ∫ax f(t) dt is continuous on [a, b], differentiable on (a, b), and:
F'(x) = d/dx [ ∫ₐˣ f(t) dt ] = f(x)
Visually, the height of the top graph f(b) equals the slope of the tangent line to the bottom graph F(x) at x = b.

2. FTC Part 2: Net Change & Signed Area Evaluation

If F is any antiderivative of f, then ∫ab f(t) dt = F(b) − F(a).
• Regions where f(t) > 0 add positive area to F(x).
• Regions where f(t) < 0 subtract area from F(x).
• Moving the lower limit a shifts F(x) vertically so that F(a) = 0 always holds. If b < a, then ∫ab f(t) dt = −∫ba f(t) dt.

3. AP Calculus FRQ Curve Sketching Rules

• F is increasing where F'(x) = f(x) > 0 (top graph is above the t-axis).
• F is decreasing where F'(x) = f(x) < 0 (top graph is below the t-axis).
• Local Extrema of F occur where f(x) changes sign (+ to − gives a local max; − to + gives a local min).
• Inflection Points of F occur where F''(x) = f'(x) changes sign (local extrema of the top graph f).

4. Interactive Canvas, Same-Axes Overlay & Presentation Mode
