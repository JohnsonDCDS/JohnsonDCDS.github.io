AP Calculus BC Numerical Integration Guide

Core Concepts & Exam Justifications

1. Left & Right Riemann Sums

• Left Sum ($L_n$): Evaluates function height at left endpoint $x_{i-1}$. If $f(x)$ is strictly increasing, $L_n$ is an underestimate. If $f(x)$ is decreasing, $L_n$ is an overestimate.
• Right Sum ($R_n$): Evaluates function height at right endpoint $x_i$. If $f(x)$ is increasing, $R_n$ is an overestimate. If $f(x)$ is decreasing, $R_n$ is an underestimate.

2. Midpoint Riemann Sum ($M_n$)

Evaluates height at midpoint $x_i^* = \frac{x_{i-1}+x_i}{2}$. Offers higher accuracy than Left/Right sums ($O(\Delta x^2)$ error). For concave up curves, Midpoint underestimates; for concave down curves, Midpoint overestimates.

3. Trapezoidal Rule ($T_n$)

Connects $(x_{i-1}, f(x_{i-1}))$ and $(x_i, f(x_i))$ with secant lines. Formula: $T_n = \frac{\Delta x}{2} [f(x_0) + 2f(x_1) + \dots + 2f(x_{n-1}) + f(x_n)]$.
• If $f(x)$ is concave up ($f'' > 0$), secant lines lie above the curve $\implies T_n$ is an overestimate.
• If $f(x)$ is concave down ($f'' < 0$), secant lines lie below the curve $\implies T_n$ is an underestimate.

4. Simpson's Parabolic Rule ($S_n$) - AP BC Topic

Fits parabolic arcs through groups of 3 consecutive points $(x_{2k-2}, x_{2k-1}, x_{2k})$. Requires $n$ to be even.
Formula: $S_n = \frac{\Delta x}{3} [f(x_0) + 4f(x_1) + 2f(x_2) + 4f(x_3) + \dots + 4f(x_{n-1}) + f(x_n)]$.
Simpson's Rule is exact for linear, quadratic, and cubic polynomials!
