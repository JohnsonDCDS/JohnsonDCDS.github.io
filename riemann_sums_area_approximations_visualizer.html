AP Calculus BC Numerical Integration Guide

Core Concepts, Keyboard Shortcuts & Window Controls

1. Left & Right Riemann Sums

• Left Sum (Ln): Evaluates function height at left endpoint xi-1. If f(x) is strictly increasing, Ln is an underestimate. If f(x) is decreasing, Ln is an overestimate.
• Right Sum (Rn): Evaluates function height at right endpoint xi. If f(x) is increasing, Rn is an overestimate. If f(x) is decreasing, Rn is an underestimate.

2. Midpoint Riemann Sum (Mn)

Evaluates height at midpoint xi* = (xi-1 + xi) / 2. Offers higher accuracy than Left/Right sums (O(Δx²) error). For concave up curves, Midpoint underestimates; for concave down curves, Midpoint overestimates.

3. Trapezoidal Rule (Tn)

Connects (xi-1, f(xi-1)) and (xi, f(xi)) with secant lines. Formula: Tn = (Δx / 2) [f(x0) + 2f(x1) + … + 2f(xn-1) + f(xn)].
• If f(x) is concave up (f'' > 0), secant lines lie above the curve ⇒ Tn is an overestimate.
• If f(x) is concave down (f'' < 0), secant lines lie below the curve ⇒ Tn is an underestimate.

4. Simpson's Parabolic Rule (Sn) - AP BC Topic

Fits parabolic arcs through groups of 3 consecutive points (x2k-2, x2k-1, x2k). Requires n to be even.
Formula: Sn = (Δx / 3) [f(x0) + 4f(x1) + 2f(x2) + 4f(x3) + … + 4f(xn-1) + f(xn)].
Simpson's Rule is exact for linear, quadratic, and cubic polynomials!
